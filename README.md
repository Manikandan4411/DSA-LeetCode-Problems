## 🧩 Problem-Solving Approach

For each problem:

1. Understand the problem
2. Identify the input and output
3. Identify constraints
4. Think of a brute-force solution
5. Improve the approach
6. Identify the DSA pattern
7. Implement the solution
8. Analyze time complexity
9. Analyze space complexity
10. Test the solution
11. Save the solution in the appropriate folder
